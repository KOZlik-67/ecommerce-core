# E-commerce Core

Ядро интернет-магазина на Python с использованием принципов ООП.

## Реализованный функционал

- **ДЗ 14.1 (Введение в ООП):** базовые классы `Product` и `Category`, счётчики категорий и товаров, загрузка данных из JSON.
- **ДЗ 14.2 (Режимы доступа):** приватные атрибуты (`__price`, `__products`), геттеры и сеттеры (`@property`), метод добавления товара `add_product()` и класс-метод `new_product()`.
- **ДЗ 15.1 (Магические методы):** строковое представление объектов (`__str__`), подсчёт общей стоимости товаров на складе через сложение (`__add__`) и итератор категории `CategoryIterator`.
- **ДЗ 16.1 (Наследование):** классы-наследники `Smartphone` и `LawnGrass`, строгое ограничение сложения товаров только одного класса через `type()`, валидация добавляемых объектов через `isinstance()`.
- **ДЗ 16.2 (Множественное наследование):**
  - Создан базовый абстрактный класс `BaseProduct` (родительский для `Product`).
  - Реализован класс-миксин `PrintMixin`, выводящий в консоль информацию о классе и его атрибутах при создании каждого объекта.

## Тестирование и качество кода

- Код проверен линтером `flake8` (соответствие PEP 8).
- Покрытие функционального кода тестами `pytest` — более 90%.
