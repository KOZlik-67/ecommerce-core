# E-commerce Core

Ядро интернет-магазина на Python с использованием ООП.

## Реализованный функционал (ДЗ 14.1)
- Описаны классы `Product` (товар) и `Category` (категория товаров).
- Для `Category` реализован подсчёт количества категорий (`category_count`) и суммарного количества продуктов (`product_count`).
- Реализована функция загрузки данных из JSON-файла (`src.utils.load_data_from_json`).
- Написаны unit-тесты на `pytest`, покрытие кода — 100%.
